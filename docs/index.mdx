# Octopus Docs

Octopus is a recoverable Git forge with normal Git developer workflows,
Walrus-backed repository durability, and Sui-anchored repository history.

## Start Here

- [Quickstart](./quickstart.md) - run Octopus, create a repo, push, clone, and
  restore.
- [Architecture](./architecture.md) - understand the server, CLI, web, Walrus,
  and Sui boundaries.
- [CLI Reference](./cli.md) - use `octopus auth`, `octopus repo`, and
  `octopus pr`.
- [API Reference](./api.md) - Git HTTP, JSON API, web session, and private
  unlock endpoints.
- [Testing](./testing.md) - checks, package tests, and acceptance coverage.
