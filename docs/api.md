# API Reference

The Octopus server exposes normal Git HTTP paths, JSON API endpoints under
`/v1`, and HTML pages for repository browsing.

## Authentication

REST and Git API calls use:

```text
x-octopus-auth-token
```

The token is a signed delegate-auth payload generated by the CLI. Tokens are
scoped:

- `rest` for JSON API calls.
- `git` for Git HTTP requests whose URL includes `.git`.

Web pages use signed HTTP-only cookies created through the wallet session flow.

## Git HTTP

| Method/path | Purpose |
|---|---|
| `GET /<owner>/<repo>.git/info/refs?service=git-upload-pack` | Clone/fetch discovery. |
| `POST /<owner>/<repo>.git/git-upload-pack` | Clone/fetch pack transfer. |
| `GET /<owner>/<repo>.git/info/refs?service=git-receive-pack` | Push discovery. |
| `POST /<owner>/<repo>.git/git-receive-pack` | Push pack transfer. |

The server serves from the local bare repo cache when available. Restore can
rebuild that cache from manifests and stored artifacts.

## Repository API

| Endpoint | Auth | Purpose |
|---|---|---|
| `GET /v1/repos` | Optional | List repositories visible to the caller. |
| `POST /v1/repos` | Delegate | Create a repository. |
| `GET /v1/repos/:owner/:repo/index` | Repo read | Return repository index metadata. |
| `POST /v1/repos/:owner/:repo/index` | Repo read | Rebuild repository index. |
| `GET /v1/repos/:owner/:repo/commits` | Repo read | List commits for a ref. |
| `GET /v1/repos/:owner/:repo/tree` | Repo read | List tree entries for a ref/path. |
| `GET /v1/repos/:owner/:repo/blob` | Repo read | Read a file by ref/path. |
| `GET /v1/repos/:owner/:repo/manifests` | Public or repo read | List artifact manifests. |
| `POST /v1/repos/:owner/:repo/restore` | Delegate write | Restore the local bare repo cache. |
| `GET /v1/repos/:owner/:repo/activity` | Repo read | List repository activity. |

Query parameters:

| Endpoint | Parameters |
|---|---|
| `GET /commits` | `ref`, `limit` where `limit` is clamped to 1..500. |
| `GET /tree` | `ref`, `path`. |
| `GET /blob` | `ref`, `path` where `path` is required. |

## Pull Request API

| Endpoint | Auth | Purpose |
|---|---|---|
| `GET /v1/repos/:owner/:repo/pulls` | Repo read | List pull requests. |
| `POST /v1/repos/:owner/:repo/pulls` | Repo write | Create a pull request. |
| `GET /v1/repos/:owner/:repo/pulls/:pull` | Repo read | Read a pull request and comparison. |

Create payload:

```json
{
  "title": "Add feature",
  "body": "Details",
  "baseRef": "main",
  "headRef": "feature-branch"
}
```

## Auth And Web Session API

| Endpoint | Auth | Purpose |
|---|---|---|
| `GET /v1/auth/config` | Public | Return server Sui/Web config for CLI and wallet login. |
| `POST /v1/auth/delegate` | Public in local mode | Register a local delegate key. Testnet mode returns 409. |
| `GET /v1/auth/web-session/challenge` | Public | Create a wallet-signable web session challenge. |
| `POST /v1/auth/web-session` | Public | Verify a wallet signature and set the web session cookie. |
| `GET /v1/auth/web-session` | Cookie | Return current web auth state. |

## Private Repo Unlock API

| Endpoint | Auth | Purpose |
|---|---|---|
| `GET /v1/repos/:owner/:repo/unlock/challenge` | Web session | Create a wallet challenge for private repo unlock. |
| `POST /v1/repos/:owner/:repo/unlock` | Web session | Verify unlock signature and add repo to session unlock set. |

## Contributor Access API

| Endpoint | Auth | Purpose |
|---|---|---|
| `POST /v1/repos/:owner/:repo/access-transaction` | Owner web session | Build a Sui transaction for contributor access changes. |
| `POST /v1/repos/:owner/:repo/activity/access` | Owner web session | Record contributor access activity after transaction completion. |
| `GET /v1/sui/transactions/:digest/wait` | Public | Wait for a Sui transaction by digest. |

## HTML Pages

| Path | Purpose |
|---|---|
| `/` | Landing page or authenticated repository dashboard. |
| `/:owner` | Owner profile/repository list. |
| `/:owner/:repo` | Repository detail page. |
| `/:owner/:repo/activity` | Repository activity. |
| `/:owner/:repo/settings/access` | Contributor management. |
